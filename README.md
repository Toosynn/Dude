# Video Studio

Toolkit for making videos, motion graphics and voiceovers with Claude Code.

| Tool | What it's for |
| --- | --- |
| [Remotion](https://www.remotion.dev) + agent skills | React-based video and motion graphics |
| [HyperFrames](https://github.com/heygen-com/hyperframes) + agent skills | HTML/GSAP to video, captions, TTS and SFX helpers |
| [Chatterbox](https://github.com/resemble-ai/chatterbox) | Open-source voiceover with voice cloning (`scripts/vo.py`) |
| Kokoro, Whisper | Lightweight TTS fallback, transcription for captions |
| `assets/sfx` | 696 CC0 Kenney SFX and 14 synthesized motion-graphics SFX |

Set up with `scripts/setup.sh`.

## Sound licenses
- `assets/sfx/kenney`: Kenney.nl packs, CC0 1.0 (via github.com/kapishdima/soundcn; its non-free WoW set is excluded).
- `assets/sfx/motion`: generated by `scripts/make_motion_sfx.sh`, no third-party material.
